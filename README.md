
💬 ChitChat
Ứng dụng nhắn tin thời gian thực lấy cảm hứng từ Facebook Messenger. Chạy tốt trên cả máy tính và điện thoại.

✨ Tính năng
Đăng ký / đăng nhập, chat real-time 1-1
Gọi thoại / gọi video, tin nhắn thoại, gửi ảnh
Thả like nhanh, đổi avatar, hình nền đoạn chat, chế độ tối
Xem ai đang online, "đang nhập...", đã gửi / đã nhận / đã xem
Tìm kiếm tin nhắn, lưu trữ đoạn chat, tắt thông báo
🚀 Chạy thử
npm install
npm run seed   # tạo tài khoản demo
npm start      # mở http://localhost:3000
Tài khoản demo (mật khẩu demo1234): demo1@demo.com, demo2@demo.com, demo3@demo.com

🛠 Công nghệ
Node.js + Express + Socket.io + SQLite (Turso) — giao diện HTML/CSS/JS thuần, PWA.
